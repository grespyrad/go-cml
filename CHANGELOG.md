# Изменения

## 0.3.0

- Репозиторий и модуль переименованы в `github.com/grespyrad/go-cml`.
- Корневой пакет называется `cml`: публичный API доступен без import alias.
- Обновлены генераторы, примеры, ссылки и архитектурные проверки.

## 0.2.3

- Parser, typed Go models, CML codec и semantic validation для CML 6.12.0.
- Декларативные инварианты, Unicode names и необязательные keyword dialects.
- Проверяемые CML-модели Go DDD-эталона с исходными и обобщёнными именами.
- Нейтральная Go-реализация выбранных правил и внешние тесты.
- Нейтральность собственных examples, fixtures и tests закреплена в AGENTS.md и OpenSpec.
- История заменена одним актуальным корневым коммитом с авторством пользователя.
